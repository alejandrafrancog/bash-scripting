# Bash Scripting 👩‍💻💻

This repository contains my personal progress in learning Bash scripting. It includes example scripts, solved exercises, personal notes, and useful resources I’ve collected along the way.

## Goals 🧠 
- Learn to write Bash scripts from basic to intermediate/advanced level
- Practice task automation on Linux/Unix systems
- Document my learning process in a clear and reusable way

## Repository Structure 📁
- scripts/: Example scripts by topic, organized in sequence

- exercises/: Solved exercises and practice tasks

- notes/: Personal notes and explanations in Markdown format

- resources/: Cheat sheets, links, and reference material
